# 🎤 Speech to Image Generator

Convert your voice into AI-generated images using Speech Recognition and Stable Diffusion.

---

## Features

- 🎤 Speech Recognition
- 🖼️ AI Image Generation
- 💾 Automatically saves generated images
- ⏱️ Displays generation time
- 🖥️ Works on CPU
- ⚡ Automatically uses NVIDIA GPU if available

---

## Technologies

- Python
- PyTorch
- Diffusers
- Stable Diffusion v1.5
- SpeechRecognition
- Hugging Face

---

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Speech-to-Image-Generator.git
```

Install requirements

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```

---

## Example

Speak

```
A futuristic city at sunset
```

The program generates an AI image automatically.

---

## Output

Generated images are saved inside

```
generated_images/
```
